### 2.2 说真话原则

**核心：** 不吹牛、不包装、敢说缺点和失败

**具体做法：**

| 场景 | ❌ 假话 | ✅ 真话 |
|------|--------|--------|
| 回测收益 | "年化 120%，稳赚" | "回测年化 120%，实盘亏 30%。回测只是第一步，别太信。" |
| 工具推荐 | "这个工具超好用" | "用了 3 个月，有几次挺准的，也有翻车的时候。好处是至少能帮我排除一些不靠谱的时机。" |
| 量化交易 | "量化稳赚不赔" | "量化就是亏得明明白白，至少知道为什么亏，不是靠感觉瞎猜。" |
| 产品评价 | "CryptoPathX 完美" | "对比预测功能好用，但数据只支持 Binance，想测多交易所的会失望。" |

**说真话检查清单（发布前必查）：**
- [ ] 这句话我会跟朋友私下说吗？
- [ ] 如果产品方看到，会不舒服吗？（舒服=可能太软）
- [ ] 有具体数字/经历支撑吗？
- [ ] 承认了什么缺点/失败吗？
- [ ] 是在教育用户，还是在分享经验？（后者更好）

## 七、风险预案

### 7.1 账号异常

**情况：** 登录失败、被限制、被禁言

**处理：**
1. 立即停止发布
2. 检查是否违反 Twitter 规则
3. 等待 24-48 小时再试
4. 如持续异常，考虑换号

### 7.2 负面评论

**情况：** 有人质疑、批评、攻击

**处理：**
1. 不争论、不回骂
2. 理性回复一次即可（说真话：承认不足）
3. 如持续攻击，拉黑处理
4. 严重情况截图留档

**回复示例：**
```
质疑："你这回测数据不准"
回复："确实，回测数据只是参考，实盘还要考虑滑点、手续费等。我一般用回测排除明显不靠谱的策略，剩下的实盘验证。"
```

### 7.3 热点翻车

**情况：** 追热点说错话、观点争议太大

**处理：**
1. 不删除推文（除非严重错误）
2. 如确实说错，发推文承认错误（说真话）
3. 复盘判断流程，优化热点筛选标准

**示例：**
```
"早上那条关于 XX 的推文，数据引用错了，更正一下：实际是 XX。抱歉，没核实清楚就发了，下次注意。"
```

### 7.4 数据异常

**情况：** 曝光量/互动量突然大幅下降

**处理：**
1. 检查是否被限流
2. 调整内容类型/发布时间
3. 增加互动频率（回复、评论）
4. 如持续 2 周无改善，复盘策略

## 十、常见问题

### Q1：第 1-2 周完全不提 CryptoPathX，那发什么？

**A：** 纯建人设，发学习日常、交易复盘、工具分享（竞品也可以）、行业观点。让粉丝先认识你这个人，不是来打广告的。

### Q2：怎么判断软广是否自然？

**A：** 问自己三个问题：
1. 如果我是粉丝，会觉得这是广告吗？
2. 产品是解决方案，还是问题来源？
3. 像朋友推荐，还是官方宣传？

### Q3：热点追不上怎么办？（如 P0 级热点，团队不在工作时间）

**A：** 
- P0 级热点（BTC 暴跌>5% 等）：无论何时，2 小时内必须响应
- P1/P2 级热点：可以等到工作时间处理
- 如确实无法及时响应，宁可不追，不要发质量差的内容

### Q4：说真话会不会得罪人/引争议？

**A：** 会，但这是筛选粉丝的过程。认同你的人会更忠诚，不认同的人本来也不是目标用户。争议内容数据往往更好（但要守住红线）。

### Q5：热点追错了（发完发现信息不实）怎么办？

**A：** 
1. 不删除推文
2. 发推文承认错误（说真话）
3. 复盘判断流程

示例：
```
"早上那条关于 XX 的推文，数据引用错了，更正一下：实际是 XX。抱歉，没核实清楚就发了，下次注意。"
```
